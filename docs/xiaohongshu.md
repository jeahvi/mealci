**标题（18 字）**：我把麦当劳点餐做成了CI流水线

**正文（约 560 字）**：

点餐最烦的不是贵，是"今天吃什么"这个死循环。

于是我做了个小东西：MealCI——把你的每一单麦当劳，当成一次代码提交。

它会跑四道流水线：

· lint（营养检查）：可乐换成零度，-147 kcal，像删掉一行冗余代码
· test（钱包测试）：把你卡包里的券穷举一遍，算出最省的那组
· build（取餐构建）：估个取餐时间，够你 review 完手头这个 PR 再走
· review（习惯评审）：翻你的历史订单吐槽——"距上次提交已 265 天，本次为深圳分部首个 commit"

四道全过，给你一张 Ready to merge 的 MR 卡；回复 merge 才下单，付钱始终你自己来。深夜下单还会被 strict 模式劝退："此单属于 hotfix，建议回滚（睡吧）"。

不是概念稿，是真能跑：营养、价格、优惠券都来自麦当劳官方 MCP 的真实数据。实测那单巨无霸＋可乐，报价 ¥35.0，一分不差。

彩蛋还有：连续 5 单同款会提示"检测到循环依赖，要不要注入一份蔬菜沙拉？"

现在它在参加 1024 程序员节创意开发大赛，排名只看 GitHub Star，所以厚着脸皮来求个收藏👇
