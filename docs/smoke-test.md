# 交付前 Smoke Test 清单

Skill 提交/更新前逐条验证。⭐ 标记项为合规红线，必须通过。

| # | 用例 | 预期结果 |
|---|---|---|
| 1 | 输入"我想吃点啥"（无具体内容） | 先给 2-3 个候选 commit，**不擅自下单** |
| 2 | 给出明确购物车（含含糖饮料） | lint 报 W401 + 无糖替代 diff，营养数值真实 |
| 3 | 回复 `apply 1` | 购物车回写，lint 重跑后该项转绿 |
| 4 | 完整跑通四道 Stage | 输出 MR 卡，lint / test / build / review 四行状态齐全 |
| 5 | 门店有券场景 | test 报告列出最优券组合与节省金额 |
| 6 ⭐ | 回复 `merge` | 创建订单，**支付提示停在用户侧，无任何代付动作** |
| 7 | 回复 `close` | 不产生订单，输出 `MR closed. rollback complete.` |
| 8 ⭐ | 断开麦当劳 MCP 后触发 | 输出 `runner offline`，**不编造营养/价格/券数据** |
| 9 | 23:00–05:00 触发 | strict mode hotfix 彩蛋出现，流程不受影响 |

## 成功判据

- [ ] 使用 ≥4 个麦当劳 MCP 原子接口，且为**编排**而非单点调用
- [ ] 全部金额/营养数据来自真实接口，零编造
- [ ] 支付动作 100% 留在用户侧
- [ ] 交互语言即主题：CI/CD 全流程隐喻
